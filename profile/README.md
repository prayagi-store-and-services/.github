# Prayagi Store And Services

**Netra Eco** - free, offline-first Android apps made in India, developed by [Deepak Kushwaha](https://github.com/prayagideepak-collab).

## Apps

| App | What it does |
| --- | --- |
| [Battery Sentinel Pro Netra](https://github.com/prayagi-store-and-services/-Battery-Sentinel-Pro-Netra) | Battery monitoring, thermal control and charging safety |
| [Netra KBC](https://github.com/prayagi-store-and-services/KBC) | Quiz app |
| [Netra Hub - Human Safety](https://github.com/prayagi-store-and-services/netra-hub) | Safety alerts |
| [SensorGuard - Prayagi Privacy](https://github.com/prayagi-store-and-services/prayagi-Privacy-) | Privacy guard |
| [Netra Player](https://github.com/prayagi-store-and-services/netra-player) | Media player |
| [Netra Trikaal](https://github.com/prayagi-store-and-services/netra-trikaal) | Private-by-design Vedic panchang, kundli and daily guidance |
| [Netra One](https://github.com/prayagi-store-and-services/netra-assistant) | Offline, on-device voice command center (Hindi/Hinglish, privacy first) |
| [Netra Eco app](https://github.com/prayagi-store-and-services/netra-eco-app) | One app to download, install and update all Netra apps |
